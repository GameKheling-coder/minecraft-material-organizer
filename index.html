Free Minecraft Litematica Material List Sorter

Litematica Sort Kering is a free Minecraft utility tool that helps players organize and calculate material lists from Litematica schematics and custom block lists. Easily sort blocks alphabetically, calculate stacks, shulker boxes, double chests, and estimate raw logs needed for massive Minecraft survival projects and mega builds.

This Minecraft schematic helper supports normal text lists and official Litematica exports, making it useful for builders, technical Minecraft players, redstone creators, SMP players, and large survival servers.

Features include:

  • ✔ Litematica material sorting
  • ✔ Stack & shulker calculations
  • ✔ Raw log conversion system
  • ✔ Search & filtering
  • ✔ Excel export support
  • ✔ Universal list parser
  • ✔ Mobile friendly interface
